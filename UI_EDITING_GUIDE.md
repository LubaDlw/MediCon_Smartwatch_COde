## Understanding the UI Framework

### LVGL (Light and Versatile Graphics Library)
- The project uses **LVGL 9** for all UI elements
- Main UI screens are generated by **SquareLine Studio** but can be manually edited
- Each screen is an `lv_obj_t` object with child widgets

### Key UI Components
- **Screens**: Full-page displays (clock, weather, notifications, settings, etc.)
- **Panels**: Container objects for grouping elements
- **Labels**: Text displays
- **Images**: Icons and graphics
- **Buttons**: Interactive elements
- **Arcs**: Circular progress indicators
- **Lists**: Scrollable item lists

## Enabling/Disabling Watchfaces

### Location: `hal/esp32/app_hal.h`

**To enable/disable watchfaces:**

1. Open `hal/esp32/app_hal.h`
2. Find the watchface section based on your board:

```c
#if defined(VIEWE_SMARTRING) || defined(VIEWE_KNOB_15) || defined(ESPS3_1_75)
    // For 466x466 displays
    #define ENABLE_FACE_756_2_466  // Uncomment to enable
    #define ENABLE_FACE_RADAR_466
    #define ENABLE_FACE_75_2
    #define ENABLE_FACE_34_2

#else
    // For 240x240 displays
    // #define ENABLE_FACE_34_2     // Commented = disabled
    #define ENABLE_FACE_75_2       // Enabled
    // #define ENABLE_FACE_79_2     // Disabled
    #define ENABLE_FACE_RADAR      // Enabled
#endif
```

3. **To enable**: Remove `//` before `#define ENABLE_FACE_XXX`
4. **To disable**: Add `//` before `#define ENABLE_FACE_XXX`

### Available Watchfaces (240x240)
- `ENABLE_FACE_34_2` - Shadow watchface
- `ENABLE_FACE_75_2` - Analog watchface
- `ENABLE_FACE_79_2` - Blue watchface
- `ENABLE_FACE_116_2` - Outline watchface
- `ENABLE_FACE_756_2` - Red watchface
- `ENABLE_FACE_RADAR` - Radar watchface
- `ENABLE_FACE_KENYA` - Kenya watchface
- `ENABLE_FACE_ELECROW` - Elecrow analog
- And more...

## Editing Main UI Screens

### Main Screens Overview
The watch has these primary screens:
- **Clock Screen** (`ui_clockScreen`) - Time display with date and weather
- **Weather Screen** (`ui_weatherScreen`) - Detailed weather forecast
- **Notification Screen** (`ui_notificationScreen`) - Message notifications
- **App List Screen** (`ui_appListScreen`) - List of installed apps
- **Settings Screen** (`ui_settingsScreen`) - Watch settings
- **Control Screen** (`ui_controlScreen`) - Music and phone controls

### Location: `src/ui/ui.c`

### Example: Changing Clock Screen Text Color

**File: `src/ui/ui.c`**

Find the clock screen initialization (search for `ui_clockScreen =`):

```c
// Hour label
ui_hourLabel = lv_label_create(ui_clockScreen);
lv_obj_set_style_text_color(ui_hourLabel, lv_color_hex(0xFFFFFF), LV_PART_MAIN | LV_STATE_DEFAULT);
//                                         Change this hex value ^^^^^^
```

**Common Colors:**
- `0xFFFFFF` - White
- `0x000000` - Black
- `0xFF0000` - Red
- `0x00FF00` - Green
- `0x0000FF` - Blue
- `0x00A8FF` - MediCon Blue (brand color)
- `0x808080` - Gray

### Example: Changing Text Size

```c
lv_obj_set_style_text_font(ui_hourLabel, &lv_font_montserrat_48, LV_PART_MAIN | LV_STATE_DEFAULT);
//                                        Change font size here ^^
```

**Available Font Sizes:**
- `lv_font_montserrat_12`
- `lv_font_montserrat_14`
- `lv_font_montserrat_16`
- `lv_font_montserrat_18`
- `lv_font_montserrat_20`
- `lv_font_montserrat_24`
- `lv_font_montserrat_32`
- `lv_font_montserrat_48`

### Example: Changing Element Position

```c
lv_obj_set_x(ui_hourLabel, 0);      // Horizontal position
lv_obj_set_y(ui_hourLabel, -50);    // Vertical position (negative = up)
lv_obj_set_align(ui_hourLabel, LV_ALIGN_CENTER);  // Alignment anchor
```

**Alignment Options:**
- `LV_ALIGN_CENTER` - Center of parent
- `LV_ALIGN_TOP_MID` - Top middle
- `LV_ALIGN_BOTTOM_MID` - Bottom middle
- `LV_ALIGN_LEFT_MID` - Left middle
- `LV_ALIGN_RIGHT_MID` - Right middle
- `LV_ALIGN_TOP_LEFT` - Top left corner
- `LV_ALIGN_BOTTOM_RIGHT` - Bottom right corner

## Creating/Modifying Apps

### Using the Sample App Template

**Location: `src/apps/sample/`**

This provides a template for creating custom apps.

### Creating a New App

1. **Copy the sample app directory:**
   ```bash
   cp -r src/apps/sample src/apps/myapp
   ```

2. **Rename files:**
   - `sample.c` → `myapp.c`
   - `sample.h` → `myapp.h`

3. **Update the app registration:**

   In `myapp.c`, find:
   ```c
   REGISTER_APP("Sample", &ui_img_app_icon_png, ui_sampleScreen, ui_sampleScreen_screen_init);
   ```
   
   Change to:
   ```c
   REGISTER_APP("My App", &ui_img_myapp_icon_png, ui_myappScreen, ui_myappScreen_screen_init);
   ```

4. **Enable the app in `hal/esp32/app_hal.h`:**
   ```c
   #define ENABLE_APP_MYAPP
   ```

5. **Add to build (if needed):**
   Update `src/common/app_manager.c` to include your app.

### Modifying Existing Apps

**Example: Steps Counter App**

**Location: `src/apps/steps/steps.c`**

#### Changing UI Colors

Find the UI element initialization:

```c
// Change title color
lv_obj_set_style_text_color(ui_stepsTitle, lv_color_hex(0x00A8FF), LV_PART_MAIN | LV_STATE_DEFAULT);
//                                          Change this ^^^^^^^^

// Change arc (progress circle) color
lv_obj_set_style_arc_color(ui_stepsArc, lv_color_hex(0x00A8FF), LV_PART_INDICATOR | LV_STATE_DEFAULT);
```

#### Changing Text Labels

```c
lv_label_set_text(ui_stepsTitle, "Steps Counter");
//                                 Change text here ^^^^^^^^^^^^
```

#### Modifying Step Detection Sensitivity

```c
static const float STEP_THRESHOLD = 0.3;  // Lower = more sensitive

```

#### Changing Step Goal (for progress arc)

```c
// In update_steps_display() function

```

## Customizing Watchfaces

### Method 1: Modifying Generated Watchfaces

**Location: `src/faces/34_2/34_2.c` (example)**

#### Adding Custom Branding

Find the init function and add a label:

```c
void init_face_34_2(void (*callback)(...)){
    // ... existing code ...
    
    // Add custom branding
    lv_obj_t *medicon_label = lv_label_create(face_34_2);

    lv_obj_set_style_text_color(medicon_label, lv_color_hex(0x00A8FF), LV_PART_MAIN | LV_STATE_DEFAULT);
    
    // ... rest of code ...
}
```

## Common UI Modifications

### 1. Changing Brand Colors Throughout

**Global brand color (MediCon Blue): `0x00A8FF`**

Search and replace in files:
- `src/ui/ui.c` - Main screens
- `src/faces/*/` - Watchfaces
- `src/apps/*/` - Apps

### 2. Adding Logo/Branding to Screens

Add at the top of any screen initialization:

```c
lv_obj_t *logo_label = lv_label_create(parent_screen);
lv_obj_set_align(logo_label, LV_ALIGN_TOP_MID);
lv_obj_set_y(logo_label, 10);
lv_label_set_text(logo_label, "MediCon");
lv_obj_set_style_text_font(logo_label, &lv_font_montserrat_20, LV_PART_MAIN | LV_STATE_DEFAULT);
lv_obj_set_style_text_color(logo_label, lv_color_hex(0x00A8FF), LV_PART_MAIN | LV_STATE_DEFAULT);
```

### 3. Changing Button Styles

```c
// Button background
lv_obj_set_style_bg_color(ui_button, lv_color_hex(0x00A8FF), LV_PART_MAIN | LV_STATE_DEFAULT);

// Button border
lv_obj_set_style_border_color(ui_button, lv_color_hex(0xFFFFFF), LV_PART_MAIN | LV_STATE_DEFAULT);
lv_obj_set_style_border_width(ui_button, 2, LV_PART_MAIN | LV_STATE_DEFAULT);

// Button corner radius
lv_obj_set_style_radius(ui_button, 10, LV_PART_MAIN | LV_STATE_DEFAULT);
```

### 4. Modifying Screen Transitions

**Location: `src/ui/ui_events.h`**

Control gesture swipes and screen transitions.

### 5. Changing Display Timeout

**Location: `src/ui/ui.c`**

Find the settings screen timeout options:

```c
lv_dropdown_set_options(ui_timeoutSelect, "15s\n30s\n60s\n120s\nAlways On");
```

Modify the values as needed.

## Building and Flashing

### Prerequisites
- PlatformIO installed
- USB drivers for your ESP32 board

### Build Process

1. **Select your board in `platformio.ini`:**
   ```ini
   [platformio]
   default_envs = lolin_s3_mini_1_28  ; Uncomment your board
   ```

2. **Build the project:**
   ```bash
   pio run
   ```

3. **Upload to device:**
   ```bash
   pio run --target upload
   ```

4. **Monitor serial output:**
   ```bash
   pio device monitor
   ```

### Testing Without Hardware

Build and run natively on PC/Mac:
```bash
pio run -e native
./test/linux_64/program    # Linux
./test/mac_64/program      # Mac
./test/windows_64/program.exe  # Windows
```

## Tips and Best Practices

1. **Always backup before editing** - Make copies of files you're modifying
2. **Test incrementally** - Make small changes and test frequently
3. **Use consistent colors** - Maintain brand identity with consistent hex colors
4. **Mind memory limits** - ESP32 has limited RAM/flash, be cautious with large images
5. **Check display resolution** - Ensure your changes work with your specific display size
6. **Use meaningful names** - When creating custom elements, use descriptive variable names
7. **Comment your changes** - Add comments explaining custom modifications
8. **Watch compiler warnings** - PlatformIO will show warnings about issues

## Troubleshooting

### Build Errors
- **"undefined reference"**: Check that feature is enabled in `app_hal.h`
- **"file not found"**: Verify file paths and includes
- **"out of memory"**: Disable unused watchfaces/apps to save space

### UI Not Displaying Correctly
- Check object alignment and positioning
- Verify parent-child relationships in LVGL objects
- Ensure colors use correct format: `lv_color_hex(0xRRGGBB)`

### Watchface Not Showing
- Confirm `#define ENABLE_FACE_XXX` is uncommented in `app_hal.h`
- Check that watchface is registered in the face array
- Verify binary files are present in `src/faces/`
